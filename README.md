# StuDorm++: Помощник в выборе комнаты в общежитии

## Описание проекта

**StuDorm++** — это проект, направленный на помощь студентам в выборе удобной комнаты в общежитии. На данный момент проект находится в стадии разработки и постепенно развивается, предоставляя пользователю удобный и интуитивно понятный интерфейс для выбора комнаты на основе различных критериев.

С помощью **StuDorm++** пользователи смогут:
- Просматривать доступные комнаты в общежитии.
- Фильтровать комнаты по различным параметрам (например, этаж, площадь, удобства).
- Оценивать комнаты на основе отзывов других пользователей.
- Следить за статусом доступности выбранных комнат в реальном времени.

На данный момент проект ещё не завершён, и в будущем будут добавлены дополнительные функции, такие как:
- Возможность бронирования комнаты онлайн.
- И другое

Проект находится в активной стадии разработки, и мы стремимся предоставить пользователям удобный инструмент для выбора наиболее подходящей комнаты в общежитии.
